# nz-tenancy-law-rag
RAG chat over NZ tenancy law (Residential Tenancies Act 1986) with a reproducible eval harness: 50+ question test set, scoring for accuracy, citation correctness and hallucination rate, and a benchmark of chunking and retrieval strategies.



Ask questions about New Zealand tenancy law and get answers cited to the exact section. Built around one question: how do you know it’s actually right?
